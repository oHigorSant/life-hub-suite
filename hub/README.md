# Life Hub (hub/)

Central pessoal em Next.js com agente de IA. A documentação geral está na raiz do repositório:

- `../README.md` — como instalar e rodar
- `../CLAUDE.md` — guia para o Claude Code que for desenvolver aqui
- `../docs/MODULES.md` — módulos, arquivos, dados e como remover cada um
- `ENGINES.md` — motores de IA (Gemini, Claude CLI, OpenRouter) e o roteador
- `CLAUDE.md` (esta pasta) — **prompt de runtime do agente** (não é o guia de desenvolvimento)

Comandos (dentro de `hub/`): `npm run dev` · `npm run build` · `npm start` (porta 4000). Configuração em `.env.local` (modelo: `.env.example`).
